# 余烬突刺 · 中线防卫战

一个无需安装依赖的纯网页生存战斗原型。直接打开 `index.html` 即可游玩。

## 操作

- **鼠标左键**：按住预演追光突刺，松开执行；消耗 1 点体力，斩中敌人会返还体力，击破敌人也会回劲。
- **鼠标右键**：按住预演逆鳞冲撞，松开执行；消耗 2 点体力。每撞到一个新敌人都会按接触法线重新变向，敌人被推出，玩家反向弹射并叠加额外位移。
- **按住 Shift**：完全暂停敌人、计时和体力回复。时停期间按住左/右键预演并排入动作队列，可看到预计命中、击破与体力；松开 Shift 后会进入慢镜回放，仍快速逐招重现，方便看清变向与命中，再恢复战斗。
- **Esc / 顶部暂停键**：暂停或继续。

时停波以玩家当前位置向外扩散，使范围内的战场逐渐褪色。左右键攻击都会把玩家永久带到位移终点；玩家没有 WASD 移动或自动回中。下一次攻击从当前站位朝鼠标方向出发，玩家被限制在战场范围内。

时停期间会同时保留所有已预备动作的完整路线。解除时停后，当前路线会随着玩家前进逐段消隐，后续路线继续显示，轮到它执行后再逐段消隐。连续命中会显示格斗式连击数；命中与击破会带来屏幕震动，击破还会触发扩散裂环与碎片爆散。

生存 3 分钟即可守住中线。击破敌人会积累经验，每次升级可从三种强化中选一项。强化包含突刺伤害、体力回复、体力上限、冲撞伤害与生命上限。

## 本原型采用的默认数值

初始生命 7、体力上限 4、体力每秒回复 0.62 点；突刺距离约 142 CSS 像素，冲撞距离约 272 CSS 像素，首次碰撞后额外反弹约 112 CSS 像素。命中突刺回复 0.38 点体力，击破额外回复 0.25 点。数值会按场地尺寸缩放。

所有图形由 Canvas 和 CSS 绘制，不依赖外部图片、字体或联网资源。
